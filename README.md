# 量子图谱查询台 · Quantum Graph Explorer

量子科技产业知识图谱的构建、查询与研判工作台。把 363 个量子科技主体与 486 条关系组织成一张可交互、可自然语言查询的图谱，并在其上叠加**技术路线判断层**与 **Wikidata 实体对齐层**。

## 图谱规模

| 维度 | 数量 |
| --- | --- |
| 节点 | 363 |
| 关系 | 486 |
| 节点类型 | 企业 86 · 学者 109 · 高校 69 · 高管 54 · 投资人 30 · 学生 15 |
| 领域标签 | 量子计算 265 · 量子通信 67 · 量子传感与测量 56 · 量子软件与算法 50 · 量子网络 26 |
| Wikidata 已对齐 | 280 / 363（77.1%） |
| 技术路线判断层 | 86 家企业 × 20 条路线 / 6 大领域 |

## 主要能力

- **自然语言查询**：中文提问自动生成 Cypher 执行（查询生成提示词内置属性枚举与等值白名单）
- **关系筛选**：按关系类型过滤边（486 → 318 → 486 全链路验证通过）
- **技术路线判断层**：86 家企业标注 `route` / `route_group` / `confidence` / `basis`，前端按领域分组下拉；无企业路线置灰保留，用于标记产业空白位
- **Wikidata 实体对齐**：三值来源枚举（`manual` / `auto-label` / `auto-alias`），三道硬门校验（P31 类型自洽、P17 国别不相交否决、人名身份证据）
- **连线形态**：节点间为二次贝塞尔平滑曲线，互反向的一对边分落曲线两侧
- **视图居中**：图形取景按可视区（扣减侧栏与面板）动态适配，桌面 / 移动 / 横屏多档位保持一致居中

## 本地运行

```bash
python llm_proxy.py
# 浏览器打开 http://127.0.0.1:8790/
```

服务同时托管页面并转发大模型接口，零第三方依赖（Python 标准库）。

Windows 下可直接双击 `start_local_server.bat`。

## 数据分层与口径

三层严格分离，**判断层不回写基础事实层**：

1. **基础事实层** `quantum_network.json` — 仅事实字段，无主观判断
2. **技术路线判断层** `tech_routes.json` — 86 家企业的路线归属与置信度
3. **构建期合并** — `build.py` 在构建时把路线字段并入节点，产物页面含合并结果

口径与字段规范见 `SCHEMA.md`；技术路线分类框架见 `docs/tech-route-report.md`；对齐过程与残余核查结论见 `docs/wikidata-alignment-status.md`。

## 关于密钥

**本项目任何位置的密钥都不会被加载。** 服务端按固定顺序读取：环境变量 → `LLM_CONFIG_FILE` 指向的文件 → 用户目录 `~/.quantum-graph/llm_server_config.json`。项目目录内若存在同名密钥文件，只告警、不加载——因为发布包会整体上传，属泄露面。前端亦不持有任何凭据。
